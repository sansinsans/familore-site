How to get help faster

Describe the issue Explain what you tried, what you expected, and what happened instead.
Mention the device Include whether you are using the web version or the Android app.
Add a screenshot If something looks wrong, a screenshot makes layout and error issues easier to trace.
Include backup context For import or export questions, mention whether you used JSON backup or local browser storage.

Common support topics

Backup and restore Questions about saving your tree as JSON and loading it again later.
Photos not appearing Profile photo display issues on web or Android builds.
Layout and zoom Tree positioning, mobile gestures, zoom controls, and visibility issues.
Data recovery Undo behavior, accidental deletion, and what can still be restored.
